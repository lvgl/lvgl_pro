## Overview

The GIF widget plays animated GIF images using LVGL's built-in AnimatedGIF decoder. The source can be an embedded array or a file.

Learn more in the [LVGL Open documentation](https://lvgl.io/docs/open/widgets/gif).

## Enumerations

**`lv_color_format`** — Color format of the buffer the gif is decoded to

| Value | Description |
| --- | --- |
| `rgb565` | 16 bit RGB |
| `rgb565_swapped` | 16 bit RGB with swapped bytes |
| `rgb888` | 24 bit RGB |
| `xrgb8888` | 32 bit RGB, the alpha byte is unused |
| `argb8888` | 32 bit RGB with alpha |

## Properties

### Parts

Style parts of the widget with local style (e.g. `style_bg_color-knob="0xff0000"`) or with style sheets (e.g. `<style name="style_knob" selector="knob">`). See [Styles](../syntax/styles) to learn more.

| Part | Description |
| --- | --- |
| `main` | Style the GIF: `image_recolor`, `image_recolor_opa` and `image_opa`. Background, border, etc can be added too. |

Properties below are the widget's XML [`<api>`](../syntax/api); see [API](../syntax/api) for how properties, parameters and elements work.

| Property | Type | Description |
| --- | --- | --- |
| `src` | `image` | The source for the gif (raw data or a file) |
| `loop_count` | `int` | Number of repeats. If not set the information form the gif will be used |
| `color_format` | `enum:lv_color_format` | Color format to decode the gif to. Set it before `src` to decode only once |
| `auto_pause_invisible` | `bool` | Pause the gif while it is not visible |
