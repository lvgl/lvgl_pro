LVGL Pro licenses are royalty-free. There are no per-unit fees.

## Free Use

- **Community**: free for personal, educational, open-source, and other non-commercial projects, and for evaluation before commercial development. It includes all Editor features, Figma Flow, the [CLI](../cli) with a daily usage limit, and online project share for public repositories. The license does not expire.
- **Renesas**: free for projects built on a Renesas MCU. See [lvgl.io/pro/renesas](https://lvgl.io/pro/renesas).

## Commercial Development

Once commercial development starts, you need a paid license:

- **Developer**: seat-based, bought online. Covers any number of products. USD 3,990 per seat per year.
- **Starter**: the full Developer license at a reduced price for startups and crowdfunded projects. Up to 2 seats per company. USD 990 per seat per year.
- **Product**: one product, up to 5 seats, valid for 5 years. USD 20,000 per product.
- **Platform**: mix seat, product, and floating licenses, with multi-year terms and a dedicated contact with an SLA. Custom price.

## Runtime XML on the Device

The licenses above cover building the UI and exporting C code. The exported C code depends only on the MIT-licensed LVGL library.

Loading XML at runtime on your device, for example for OTA UI updates, needs a separate runtime license. Email [lvgl@lvgl.io](mailto:lvgl@lvgl.io) to get one.
